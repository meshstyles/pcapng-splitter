# pcapng splitter

[![Build and Deploy](https://github.com/meshstyles/pcapng-splitter/actions/workflows/deploy.yml/badge.svg)](https://github.com/meshstyles/pcapng-splitter/actions/workflows/deploy.yml)

This tool splits a selected pcapng file to packages.
It views them line by line.
It uses react just for minor conveniences.

## note

This only works for smaller pcapng files.

# how to use

run `npm run dev` to start the server and use `npm run build` to initate a build of the page.
